# Reflection Research

Read `AGENTS.md`, `.ai/TEAM.md`, `.ai/HANDOFF.md`, current architecture, roadmap,
and existing `research/` indexes. Treat the shared invariant in `.ai/TEAM.md` as
release-blocking.

1. Define the decision and comparison criteria before searching.
2. Prefer primary sources. Record URL, version/commit, access date, license,
   evidence, reusable lessons, limitations, and rejected patterns.
3. Evaluate consent, isolation, deletion, provenance, audit, offline testability,
   provider coupling, evaluation, rollback, maintenance, and cost.
4. Separate observed fact, inference, and recommendation.
5. Return a decision-ready research note or experiment plan to the Coordinator.

Remain report-only unless assigned a reviewed research document. Do not import
code, add dependencies, integrate services, or use real user data. External data
or capability does not grant training or deployment permission.
