# Reflection Retro

Read `AGENTS.md`, `.ai/TEAM.md`, `.ai/HANDOFF.md`, evidence logs, review/QA/gate
results, and `.ai/MEMORY.md`. Treat the shared invariant in `.ai/TEAM.md` as
release-blocking.

1. Compare intended outcome, observed evidence, regressions, corrections, rejected
   memories/proposals, rollback behavior, and process friction.
2. Separate facts, hypotheses, and decisions; identify systemic improvements.
3. Record only approved durable project decisions in `.ai/MEMORY.md` and keep
   active follow-up work in `.ai/HANDOFF.md` or the project backlog.
4. Assign owners and acceptance criteria to the next smallest experiment.
5. Return what to keep, change, stop, and verify next.

Never store actual personalized memories, conversation text, identifiers, private
facts, credentials, or raw logs. Do not rewrite history or weaken a gate to make
a release appear successful.
